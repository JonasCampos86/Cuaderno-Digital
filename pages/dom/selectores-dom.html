Selectores del DOM

Cómo encontrar elementos del HTML desde JavaScript para poder leerlos o modificarlos.

1. Qué es el DOM

El DOM es la representación del documento HTML como un árbol de objetos que JavaScript puede leer y modificar.

El DOM es el puente entre HTML y JavaScript.

2. Objeto document

document es el punto de entrada principal al DOM. 

document.getElementById()
document.querySelector()
document.querySelectorAll()

3. Selectores principales

Los selectores permiten encontrar elementos que ya existen en el documento. 

const parrafo = document.querySelector("p");

const todosLosParrafos = document.querySelectorAll("p");

querySelector() puede devolver null si no encuentra ningún elemento.

4. Colecciones

Algunos selectores devuelven un único elemento y otros devuelven colecciones como HTMLCollection o NodeList.

Una colección no es un elemento individual. Para acceder a un elemento concreto hay que usar un índice o recorrerla. 

const parrafos = document.querySelectorAll("p");

console.log(parrafos[0].textContent);
