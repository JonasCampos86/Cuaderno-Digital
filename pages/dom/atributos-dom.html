Gestión de atributos del DOM

Cómo leer, crear, modificar y eliminar atributos HTML desde JavaScript.

1. Qué son los atributos

Los atributos son información adicional que escribimos dentro de una etiqueta HTML.

Sirven para identificar elementos, configurar su comportamiento, añadir rutas, aplicar estilos, guardar datos o modificar cómo funciona un elemento. 

<div id="caja" class="rojo" title="Caja principal"></div>

En este ejemplo, el div tiene tres atributos: id, class y title.

Los atributos pertenecen al HTML y aportan información extra a una etiqueta.

2. Del HTML al DOM

Cuando el navegador lee el HTML, construye una representación interna llamada DOM.

Esa representación no es texto plano: es una estructura de objetos que JavaScript puede leer y modificar. 

<div id="caja" class="rojo"></div>
        ↓
Objeto DOM
        ↓
{
  id: "caja",
  className: "rojo",
  classList: DOMTokenList,
  style: CSSStyleDeclaration
}

El atributo está escrito en el HTML; la propiedad vive en el objeto DOM que JavaScript maneja. 

<input id="nombre" required>
HTML
        ↓
<input id="nombre" required>
        ↓
Objeto DOM
        ↓
{
  id: "nombre",
  required: true
}

Atributo HTML y propiedad DOM están relacionados, pero no siempre son exactamente lo mismo.

3. Propiedades y métodos genéricos

En JavaScript podemos trabajar con atributos principalmente de dos formas: mediante propiedades o mediante métodos genéricos. 

element.id;
element.className;
element.disabled;
element.style;
element.getAttribute("id");
element.setAttribute("id", "caja");
element.hasAttribute("id");
element.removeAttribute("id");

Las propiedades son cómodas para atributos conocidos; los métodos genéricos sirven para trabajar con cualquier atributo. 

const caja = document.querySelector("div");

console.log(caja.id);
console.log(caja.className);

caja.id = "divConID";
caja.className = "importante negrita";

En HTML usamos class, pero en JavaScript la propiedad se llama className.

4. classList

Si usamos className, sustituimos todas las clases del elemento de golpe. 

<div class="rojo grande activo"></div>
caja.className = "azul";
<div class="azul"></div>

Para trabajar con clases de forma más controlada usamos classList. 

caja.classList.add("activo");

caja.classList.remove("rojo");

caja.classList.toggle("oculto");

caja.classList.contains("grande");

caja.classList.replace("rojo", "azul");

classList es la forma más limpia de añadir, quitar o comprobar clases sin sobrescribir todas las demás.

5. Acceso al atributo style

El atributo style también tiene un tratamiento especial desde JavaScript. 

<div style="color: red; font-size: 20px;"></div>
const caja = document.querySelector("div");

caja.style.color = "blue";

caja.style.fontSize = "24px";

caja.style.backgroundColor = "yellow";

caja.style.borderRadius = "10px";

En JavaScript, las propiedades CSS con guion se escriben en camelCase.

font-size pasa a ser fontSize.

background-color pasa a ser backgroundColor.

Modificar todo el atributo style como texto suele ser menos recomendable porque puede reemplazar estilos anteriores.

6. Métodos genéricos para atributos

Los métodos genéricos permiten trabajar con atributos por su nombre. 

element.getAttribute("nombreDelAtributo");

element.setAttribute("nombreDelAtributo", "valor");

element.hasAttribute("nombreDelAtributo");

element.removeAttribute("nombreDelAtributo");

getAttribute() lee el valor de un atributo.

setAttribute() crea o modifica un atributo.

hasAttribute() comprueba si existe un atributo concreto.

hasAttributes() comprueba si el elemento tiene algún atributo.

getAttributeNames() devuelve los nombres de todos los atributos.

removeAttribute() elimina un atributo. 

<div id="caja" class="rojo" pepito="1234"></div>
const caja = document.querySelector("div");

console.log(caja.getAttribute("id"));
console.log(caja.getAttribute("class"));
console.log(caja.getAttribute("pepito"));
console.log(caja.getAttribute("noExiste")); // null

removeAttribute() elimina el atributo del elemento, no elimina el elemento del DOM.

7. Atributos data-* y dataset

Técnicamente podemos crear atributos inventados, pero en HTML moderno no es buena práctica hacerlo sin criterio. 

<div pepito="1234"></div>

Para guardar datos personalizados en un elemento, lo correcto es usar atributos data-*. 

<article data-id="20" data-category="libros"></article>

Si queremos guardar datos propios en HTML, es mejor usar data-* que inventar atributos como pepito.

dataset permite acceder desde JavaScript a los atributos data-*. 

const articulo = document.querySelector("article");

console.log(articulo.dataset.id);
console.log(articulo.dataset.category);
<div data-user-id="15"></div>
const div = document.querySelector("div");

console.log(div.dataset.userId);

data-user-id se convierte en dataset.userId. 

articulo.dataset.id = "30";

articulo.dataset.estado = "activo";

Modificar dataset modifica los atributos data-* del elemento.

8. Atributos booleanos

Algunos atributos HTML son booleanos. Su funcionamiento depende de si el atributo existe o no existe. 

<input required>

<button disabled>Enviar</button>

<input type="checkbox" checked>

<option selected>Opción 1</option>

<div hidden>Contenido oculto</div>

En los atributos booleanos, lo importante es si el atributo está presente.

button.setAttribute("disabled", false) no desactiva disabled. 

button.setAttribute("disabled", false);
<button disabled="false">Enviar</button>

Como el atributo disabled existe, el botón queda deshabilitado igualmente. 

button.disabled = true;

button.disabled = false;

button.setAttribute("disabled", "");

button.removeAttribute("disabled");

Para atributos booleanos conocidos, suele ser más claro usar propiedades como button.disabled = true o button.disabled = false.

9. toggleAttribute()

toggleAttribute() añade o elimina un atributo. 

input.toggleAttribute("required");
Si el atributo existe
        ↓
Lo elimina

Si el atributo no existe
        ↓
Lo crea

Es especialmente útil con atributos booleanos. 

input.toggleAttribute("required", true);

input.toggleAttribute("required", false);

El segundo parámetro de toggleAttribute() permite controlar el resultado en vez de alternarlo a ciegas.

10. Atributo HTML y valor actual

A veces leer un atributo con getAttribute() no es exactamente lo mismo que leer una propiedad. 

<input value="Jonás">
const input = document.querySelector("input");

console.log(input.getAttribute("value"));

console.log(input.value);

Al principio ambos pueden parecer iguales, pero si el usuario cambia el valor del input en la página, la propiedad value puede cambiar.

getAttribute("value") lee el atributo original.

input.value lee el valor actual del objeto DOM.

En algunos elementos, el atributo puede representar el valor inicial y la propiedad puede representar el valor actual.

Esta diferencia se nota especialmente en formularios.

11. Resumen final

Los atributos son información adicional escrita dentro de una etiqueta HTML.

El navegador transforma el HTML en objetos del DOM.

Muchos atributos se reflejan como propiedades del objeto DOM.

Atributo HTML y propiedad DOM están relacionados, pero no siempre son idénticos.

classList es la forma más limpia de trabajar con clases.

dataset es la forma más cómoda de trabajar con atributos data-*.

Los atributos booleanos dependen de su presencia, no de valores como "true" o "false".

Usar setAttribute("disabled", false) mantiene disabled activo porque el atributo sigue existiendo.

Gestionar atributos desde JavaScript permite modificar la identidad, el comportamiento, los estilos, los datos y el estado de los elementos del DOM.
