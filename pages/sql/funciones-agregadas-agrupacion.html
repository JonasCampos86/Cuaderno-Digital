Funciones agregadas y agrupación en MySQL

Resumir datos, formar grupos y filtrar resultados con la tabla film de Sakila.

Antes de empezar

Las funciones agregadas permiten realizar cálculos sobre varias filas y devolver un único resultado para todo el conjunto o para cada grupo de datos.

Los ejemplos utilizan principalmente la tabla film de la base de datos sakila.

WHERE filtra filas, GROUP BY forma grupos y HAVING filtra esos grupos.

Antes de ejecutar los ejemplos, la base sakila y sus datos deben estar importados en tu servidor. Puedes consultar la guía oficial de instalación de Sakila.

Selecciona la base de datos: 

USE sakila;

Las consultas concretas utilizan film. Los bloques con nombres como tabla, columna o FUNCION_AGREGADA son plantillas que debes adaptar; no se ejecutan literalmente.

1. Qué es una función agregada

Una función agregada recibe los valores de varias filas y calcula un único resultado.

Funciones agregadas principales

Función Resultado
COUNT() Cuenta filas o valores.
SUM() Suma valores numéricos.
AVG() Calcula la media de valores numéricos.
MIN() Obtiene el valor mínimo.
MAX() Obtiene el valor máximo.
GROUP_CONCAT() Une en una cadena los valores de las filas de cada grupo.

Sin GROUP BY, la función agregada calcula un resultado para todas las filas que superan el filtro.

Con GROUP BY, la función agregada calcula un resultado independiente para cada grupo.

En las funciones de este tema, COUNT(columna), SUM(), AVG(), MIN(), MAX() y GROUP_CONCAT() ignoran los valores NULL. COUNT(*) cuenta las filas completas.

En una agregación global sin filas coincidentes, COUNT() devuelve 0; SUM(), AVG(), MIN(), MAX() y GROUP_CONCAT() devuelven NULL.

2. COUNT()

COUNT() se utiliza para contar filas o valores.

2.1. COUNT(*)

Cuenta todas las filas que forman parte del resultado, aunque alguna de sus columnas contenga NULL.

Contar todas las películas: 

SELECT COUNT(*) AS total_peliculas
FROM film;

2.2. COUNT(columna)

Cuenta únicamente las filas en las que la columna indicada no contiene NULL.

Contar los valores no nulos de original_language_id: 

SELECT COUNT(original_language_id) AS idiomas_originales_registrados
FROM film;

COUNT(*) y COUNT(columna) pueden devolver resultados diferentes si la columna contiene valores NULL.

2.3. COUNT(DISTINCT columna)

Cuenta cuántos valores diferentes y no nulos existen en una columna.

Contar las clasificaciones distintas: 

SELECT COUNT(DISTINCT rating) AS clasificaciones_distintas
FROM film;

2.4. COUNT() con WHERE

Primero se filtran las filas y después se cuentan únicamente las que cumplen la condición.

Contar las películas con clasificación PG: 

SELECT COUNT(*) AS peliculas_pg
FROM film
WHERE rating = 'PG';

COUNT(*) cuenta filas; COUNT(columna) cuenta valores no nulos; COUNT(DISTINCT columna) cuenta valores diferentes no nulos.

3. SUM()

SUM() suma los valores numéricos de una columna.

Sintaxis básica

SELECT SUM(columna)
FROM tabla;

Sumar el coste de reposición de todas las películas: 

SELECT SUM(replacement_cost) AS costo_total
FROM film;

Sumar el coste de reposición de las películas PG: 

SELECT SUM(replacement_cost) AS costo_total_pg
FROM film
WHERE rating = 'PG';

Utiliza SUM() con datos numéricos. Los valores NULL no participan en la suma.

4. AVG()

AVG() calcula la media aritmética de los valores numéricos no nulos.

Sintaxis básica

SELECT AVG(columna)
FROM tabla;

Calcular la duración media de las películas NC-17: 

SELECT AVG(length) AS duracion_promedio
FROM film
WHERE rating = 'NC-17';

Calcular la duración media de cada clasificación: 

SELECT rating,
       AVG(length) AS duracion_promedio
FROM film
GROUP BY rating;

Los valores NULL no se consideran ni en la suma ni en la cantidad de valores utilizada para calcular la media.

5. MIN() y MAX()

MIN() devuelve el valor más pequeño y MAX() devuelve el más grande.

Obtener la duración mínima y máxima: 

SELECT MIN(length) AS duracion_minima,
       MAX(length) AS duracion_maxima
FROM film;

Obtener la duración mínima y máxima de cada clasificación: 

SELECT rating,
       MIN(length) AS duracion_minima,
       MAX(length) AS duracion_maxima
FROM film
GROUP BY rating;

Estas funciones también pueden utilizarse con fechas y textos cuando tenga sentido buscar el menor o el mayor valor según el orden correspondiente.

Con GROUP BY, MIN() y MAX() se calculan por separado dentro de cada grupo.

6. GROUP BY

GROUP BY reúne en un mismo grupo las filas que comparten el mismo valor en una o varias columnas.

Después, las funciones agregadas calculan un resultado para cada uno de esos grupos.

Sintaxis básica

SELECT columna_agrupada,
       FUNCION_AGREGADA(columna)
FROM tabla
GROUP BY columna_agrupada;

6.1. Agrupar por una columna

Contar las películas de cada año de estreno: 

SELECT release_year,
       COUNT(*) AS total_peliculas
FROM film
GROUP BY release_year;

Contar las películas por combinación de características especiales: 

SELECT special_features,
       COUNT(*) AS total_peliculas
FROM film
GROUP BY special_features;

Si special_features contiene varios elementos, GROUP BY agrupa por el contenido completo almacenado en la columna, no por cada elemento de forma independiente.

6.2. Agrupar por varias columnas

Cuando se indican varias columnas, cada combinación distinta de sus valores forma un grupo independiente.

Agrupar por clasificación y características especiales: 

SELECT rating,
       special_features,
       COUNT(*) AS total_peliculas,
       AVG(length) AS duracion_promedio,
       SUM(replacement_cost) AS costo_total
FROM film
GROUP BY rating, special_features
ORDER BY rating, total_peliculas DESC;

Se crea un grupo por cada combinación de rating y special_features.

Sin ROLLUP, GROUP BY rating, special_features y GROUP BY special_features, rating forman los mismos grupos. El orden de escritura no garantiza el orden del resultado: para eso usamos ORDER BY. Con WITH ROLLUP, el orden sí determina qué subtotales se generan.

6.3. Columnas permitidas en SELECT

Para las consultas de esta lección seguiremos esta regla práctica: cada columna mostrada en SELECT debe cumplir una de estas condiciones:

  • Aparecer en GROUP BY.
  • Estar dentro de una función agregada.

Ejemplo correcto: 

SELECT rating,
       COUNT(*) AS total_peliculas,
       AVG(length) AS duracion_promedio
FROM film
GROUP BY rating;

Mostrar una columna que no está agrupada ni agregada puede producir un error con el modo ONLY_FULL_GROUP_BY o un resultado ambiguo si dicho control no está activo.

Incluye en GROUP BY las columnas no agregadas que quieras mostrar.

MySQL también admite casos de dependencia funcional: por ejemplo, agrupar por una clave primaria puede permitir mostrar otras columnas de esa misma tabla. Es una excepción a la regla didáctica; no hace falta desactivar ONLY_FULL_GROUP_BY.

7. Diferencia entre WHERE y HAVING

WHERE y HAVING filtran datos en momentos diferentes.

Cláusula Momento de aplicación Qué filtra
WHERE Antes de formar los grupos. Filas individuales.
HAVING Después de formar los grupos y calcular los agregados. Grupos completos.

7.1. Filtrar filas con WHERE

Agrupar únicamente películas con una tarifa superior a 2.99: 

SELECT rating,
       COUNT(*) AS total_peliculas
FROM film
WHERE rental_rate > 2.99
GROUP BY rating;

WHERE excluye de la consulta las películas que no cumplen la condición. Después, GROUP BY organiza las filas restantes. No se borran registros de la tabla.

7.2. Filtrar grupos con HAVING

Mostrar solo las clasificaciones con más de 50 películas: 

SELECT rating,
       COUNT(*) AS total_peliculas
FROM film
GROUP BY rating
HAVING COUNT(*) > 50;

Mostrar solo las clasificaciones cuya duración media supera 100 minutos: 

SELECT rating,
       AVG(length) AS duracion_promedio
FROM film
GROUP BY rating
HAVING AVG(length) > 100;

7.3. Utilizar un alias en HAVING

MySQL permite utilizar en HAVING el alias asignado a una expresión de SELECT.

Ejemplo equivalente: 

SELECT rating,
       AVG(length) AS duracion_promedio
FROM film
GROUP BY rating
HAVING duracion_promedio > 100;

El alias de SELECT no puede utilizarse en WHERE. Ese alias no está disponible para el filtrado de las filas de origen.

7.4. Combinar WHERE y HAVING

Una misma consulta puede filtrar primero las filas y después los grupos resultantes.

Aplicar ambos filtros: 

SELECT rating,
       COUNT(*) AS total_peliculas,
       AVG(length) AS duracion_promedio
FROM film
WHERE replacement_cost >= 15
GROUP BY rating
HAVING AVG(length) > 100
ORDER BY duracion_promedio DESC;

Utiliza WHERE para condiciones sobre filas y HAVING para condiciones sobre resultados agregados.

8. Agrupar mediante CASE

CASE permite crear categorías calculadas a partir de una o varias condiciones.

Estructura básica

CASE
    WHEN condicion_1 THEN 'Resultado 1'
    WHEN condicion_2 THEN 'Resultado 2'
    ELSE 'Resultado restante'
END

Dividir las películas en segmentos de coste: 

SELECT CASE
           WHEN replacement_cost < 15 THEN 'Bajo'
           WHEN replacement_cost BETWEEN 15 AND 20 THEN 'Medio'
           ELSE 'Alto'
       END AS segmento_costo,
       COUNT(*) AS cantidad,
       AVG(rental_rate) AS tarifa_promedio,
       AVG(length) AS duracion_promedio
FROM film
GROUP BY segmento_costo
ORDER BY cantidad DESC;

Categorías creadas por el ejemplo

Condición Categoría
replacement_cost < 15 Bajo
replacement_cost BETWEEN 15 AND 20 Medio
replacement_cost > 20 Alto

BETWEEN 15 AND 20 incluye ambos límites: 15 y 20.

MySQL permite utilizar el alias segmento_costo en GROUP BY.

Si la columna pudiera contener NULL, ninguna comparación sería verdadera y ese valor llegaría al ELSE. En ese caso habría que tratar NULL de forma explícita para no clasificarlo incorrectamente.

CASE crea la categoría y GROUP BY reúne las filas que pertenecen a ella.

9. Subconsultas con funciones agregadas

Una subconsulta puede calcular un valor agregado que la consulta principal utiliza para comparar, filtrar o calcular nuevos resultados.

9.1. Comparar cada fila con la media global

Películas cuya duración supera la media general: 

SELECT title,
       length
FROM film
WHERE length > (
    SELECT AVG(length)
    FROM film
)
ORDER BY length DESC;

La subconsulta calcula una única duración media. La consulta principal compara la duración de cada película con ese valor.

En este patrón de comparación escalar, la subconsulta debe proporcionar una sola columna y como máximo una fila. AVG(length) sin GROUP BY devuelve una fila con la media, o con NULL si no hay valores que promediar.

9.2. Comparar cada grupo con la media global

Comparar la tarifa media de cada clasificación con la tarifa media general: 

SELECT rating,
       AVG(rental_rate) AS tarifa_promedio,
       (SELECT AVG(rental_rate) FROM film) AS tarifa_global,
       AVG(rental_rate) - (
           SELECT AVG(rental_rate)
           FROM film
       ) AS diferencia
FROM film
GROUP BY rating
ORDER BY diferencia DESC;
  • tarifa_promedio contiene la media de cada clasificación.
  • tarifa_global contiene la media de todas las películas.
  • diferencia muestra cuánto se separa la media de cada grupo respecto a la media global.

Interpretación de diferencia

Resultado Significado
Mayor que 0 La media del grupo supera la media global.
Igual a 0 La media del grupo coincide con la media global.
Menor que 0 La media del grupo está por debajo de la media global.

La consulta principal trabaja con los grupos; la subconsulta independiente calcula el valor global de referencia.

10. GROUP_CONCAT()

GROUP_CONCAT() reúne en una sola cadena los valores no nulos de varias filas pertenecientes al mismo grupo.

Sintaxis de MySQL

GROUP_CONCAT(
    [DISTINCT] expresion
    [ORDER BY expresion]
    [SEPARATOR 'separador']
)

Permite las siguientes opciones:

  • DISTINCT: elimina los valores duplicados antes de construir la cadena.
  • ORDER BY: ordena internamente los valores que se van a concatenar.
  • SEPARATOR: sustituye la coma utilizada como separador predeterminado.

La sintaxis de GROUP_CONCAT() en MySQL no incluye una opción LIMIT. Los corchetes de la plantilla indican partes opcionales y no se escriben literalmente.

La cadena puede truncarse al alcanzar group_concat_max_len (1024 bytes por defecto). Una lista de títulos extensa puede quedar incompleta: revisa ese límite cuando necesites conservar todos los valores.

10.1. Listar valores de cada grupo

Reunir los títulos de cada clasificación: 

SELECT rating,
       GROUP_CONCAT(
           title
           ORDER BY title
           SEPARATOR ' | '
       ) AS titulos,
       COUNT(*) AS total_peliculas
FROM film
GROUP BY rating
ORDER BY total_peliculas DESC;

El ORDER BY title situado dentro de GROUP_CONCAT() ordena los títulos antes de unirlos.

El ORDER BY situado al final de la consulta ordena las filas del resultado, pero no los valores dentro de la cadena creada por GROUP_CONCAT().

10.2. Eliminar duplicados

Mostrar las clasificaciones distintas de cada conjunto de características: 

SELECT special_features,
       GROUP_CONCAT(
           DISTINCT rating
           ORDER BY rating
           SEPARATOR ', '
       ) AS ratings_disponibles,
       AVG(replacement_cost) AS costo_promedio
FROM film
GROUP BY special_features
ORDER BY COUNT(*) DESC;
  • DISTINCT evita repetir una misma clasificación dentro de la cadena de cada grupo.
  • ORDER BY rating organiza las clasificaciones dentro de la cadena.
  • SEPARATOR ', ' separa los valores mediante una coma y un espacio.

11. Limitar una lista creada con GROUP_CONCAT()

Como GROUP_CONCAT() no dispone de LIMIT en MySQL, puede combinarse con SUBSTRING_INDEX() para conservar solo una parte de la cadena.

11.1. SUBSTRING_INDEX()

SUBSTRING_INDEX(cadena, separador, cantidad) devuelve la parte de una cadena situada antes o después de un número determinado de apariciones del separador.

Sintaxis básica

SUBSTRING_INDEX(cadena, separador, cantidad)

Con una cantidad positiva, devuelve lo que hay antes de la aparición número cantidad del separador, contando desde la izquierda. Si no hay tantas apariciones, devuelve toda la cadena.

Mostrar hasta cinco títulos por clasificación: 

SELECT rating,
       SUBSTRING_INDEX(
           GROUP_CONCAT(
               title
               ORDER BY title
               SEPARATOR ' | '
           ),
           ' | ',
           5
       ) AS muestra_titulos,
       COUNT(*) AS total_peliculas
FROM film
GROUP BY rating
ORDER BY total_peliculas DESC;

Interpretación del ejemplo

  1. GROUP BY rating forma un grupo por cada clasificación.
  2. GROUP_CONCAT() ordena por título y une los valores de cada grupo.
  3. SUBSTRING_INDEX() extrae la parte anterior al quinto separador.
  4. COUNT(*) cuenta todas las películas del grupo, no solo las incluidas en la muestra.

Sin un ORDER BY interno, no puede controlarse qué títulos aparecen al principio de la cadena.

El ORDER BY title interno permite tomar la muestra en orden de título. Si distintos títulos empatan según la intercalación y necesitas un desempate estable, puedes añadir film_id al orden interno.

Este patrón recorta una cadena ya construida; no limita previamente las filas que recibe GROUP_CONCAT(). Solo representa hasta cinco títulos completos si el separador no aparece dentro de los títulos y la cadena no se ha truncado antes de completar esa muestra.

El separador utilizado por SUBSTRING_INDEX() debe coincidir exactamente con el definido mediante SEPARATOR.

12. WITH ROLLUP

WITH ROLLUP añade filas de resumen a un resultado agrupado.

Puede generar subtotales para los niveles de agrupación y un total general.

Sintaxis básica

SELECT columnas,
       FUNCION_AGREGADA(columna)
FROM tabla
GROUP BY columna_1, columna_2 WITH ROLLUP;

Contar películas con subtotales y total general: 

SELECT IFNULL(rating, 'TOTAL') AS rating,
       IFNULL(release_year, 'SUBTOTAL') AS anio,
       COUNT(*) AS total
FROM film
GROUP BY rating, release_year WITH ROLLUP;

Con el orden GROUP BY rating, release_year WITH ROLLUP, el resultado incluye:

  • El total de cada combinación de rating y release_year.
  • Un subtotal para cada valor de rating.
  • Un total general de todas las filas.

Las filas adicionales utilizan NULL en las columnas cuyo nivel se está resumiendo.

IFNULL() sustituye esos valores por textos más fáciles de interpretar.

IFNULL() no distingue entre un NULL real de los datos y un NULL generado por WITH ROLLUP.

MySQL dispone de GROUPING() para realizar esa distinción cuando sea necesario.

El orden de las columnas de GROUP BY determina la jerarquía de los subtotales generados por WITH ROLLUP.

13. Orden de escritura de una consulta agrupada

Las cláusulas deben escribirse siguiendo este orden: 

SELECT columnas_y_agregados
FROM tabla
WHERE condiciones_sobre_filas
GROUP BY columnas_de_agrupacion
HAVING condiciones_sobre_grupos
ORDER BY criterio_de_ordenacion
LIMIT cantidad;

Cambiar el orden sintáctico de estas cláusulas provoca un error. Las cláusulas que no necesites pueden omitirse.

14. Orden lógico de ejecución

Aunque SELECT se escribe primero, las partes de una consulta se interpretan conceptualmente en otro orden.

Orden lógico simplificado

Posición Etapa Función
1 FROM Determina la tabla de origen.
2 WHERE Filtra las filas individuales.
3 GROUP BY y agregación Forma los grupos y calcula los agregados necesarios.
4 HAVING Filtra los grupos.
5 SELECT Construye las columnas del resultado a partir de los grupos y agregados.
6 DISTINCT Elimina filas duplicadas del resultado seleccionado.
7 ORDER BY Ordena el resultado.
8 LIMIT Limita el número de filas devueltas.

Es un modelo lógico para comprender el resultado, no una secuencia física obligatoria: el optimizador puede elegir otra estrategia. Los agregados necesarios para HAVING ya deben estar disponibles al filtrar los grupos.

MySQL permite utilizar alias de SELECT en GROUP BY, HAVING y ORDER BY, aunque esas etapas aparezcan en distintas posiciones dentro del modelo lógico.

15. Patrones fundamentales

Estas plantillas reúnen las estructuras principales. Sustituye los nombres genéricos y las condiciones antes de ejecutarlas.

15.1. Calcular un agregado global

SELECT FUNCION_AGREGADA(columna) AS resultado
FROM tabla;

15.2. Calcular un agregado después de filtrar filas

SELECT FUNCION_AGREGADA(columna) AS resultado
FROM tabla
WHERE condicion;

15.3. Calcular un agregado por grupos

SELECT columna_agrupada,
       FUNCION_AGREGADA(columna) AS resultado
FROM tabla
GROUP BY columna_agrupada;

15.4. Filtrar grupos

SELECT columna_agrupada,
       FUNCION_AGREGADA(columna) AS resultado
FROM tabla
GROUP BY columna_agrupada
HAVING FUNCION_AGREGADA(columna) condicion;

En esta última plantilla, condicion representa la comparación que falta, por ejemplo > 10.

15.5. Filtrar filas y después grupos

SELECT columna_agrupada,
       FUNCION_AGREGADA(columna) AS resultado
FROM tabla
WHERE condicion_sobre_filas
GROUP BY columna_agrupada
HAVING condicion_sobre_agregados;

15.6. Comparar con un agregado calculado por una subconsulta

SELECT columnas
FROM tabla
WHERE columna > (
    SELECT AVG(columna)
    FROM tabla
);

15.7. Crear categorías y agruparlas

SELECT CASE
           WHEN condicion_1 THEN 'Categoria 1'
           WHEN condicion_2 THEN 'Categoria 2'
           ELSE 'Categoria 3'
       END AS categoria,
       COUNT(*) AS cantidad
FROM tabla
GROUP BY categoria;

16. Errores frecuentes

Error Corrección
Utilizar WHERE COUNT(*) > 10. Las condiciones sobre agregados del grupo van en HAVING.
Mostrar columnas no agregadas sin justificar su valor dentro de cada grupo. Como regla práctica, inclúyelas en GROUP BY o aplícales una función agregada.
Pensar que COUNT(columna) cuenta también los valores NULL. Utiliza COUNT(*) para contar todas las filas.
Confundir COUNT(*) con COUNT(DISTINCT columna). Elige entre contar filas y contar valores diferentes no nulos.
Utilizar HAVING para un filtro normal sobre las filas de origen. Aplica ese filtro con WHERE antes de agrupar.
GROUP_CONCAT(... LIMIT 5). MySQL no admite LIMIT dentro de esa función. Puedes recortar la cadena con SUBSTRING_INDEX() respetando sus limitaciones.
Colocar ORDER BY solo al final esperando ordenar el interior de GROUP_CONCAT(). Añade un ORDER BY dentro de GROUP_CONCAT().
Usar separadores diferentes en GROUP_CONCAT() y SUBSTRING_INDEX(). Utiliza exactamente el mismo separador en ambas funciones.
Interpretar todos los NULL de un resultado con ROLLUP como subtotales. También pueden existir NULL reales. GROUPING() permite distinguirlos.
Considerar obligatorio indexar todas las columnas utilizadas en GROUP BY. Los índices pueden mejorar algunas consultas, pero su utilidad depende de la consulta y de los datos.

17. Resumen final

Elemento Uso principal
COUNT(*) Contar todas las filas.
COUNT(columna) Contar valores no nulos.
COUNT(DISTINCT columna) Contar valores diferentes no nulos.
SUM() Sumar valores numéricos.
AVG() Calcular una media.
MIN() Obtener el valor mínimo.
MAX() Obtener el valor máximo.
GROUP BY Formar grupos.
WHERE Filtrar filas antes de agrupar.
HAVING Filtrar grupos después de calcular los agregados.
CASE Crear categorías calculadas.
GROUP_CONCAT() Unir los valores de cada grupo en una cadena.
SUBSTRING_INDEX() Extraer una parte de una cadena utilizando un separador.
WITH ROLLUP Añadir subtotales y un total general.
Subconsulta agregada Calcular un valor de referencia para la consulta principal.

Esquema lógico: FROM → WHERE → agrupación y agregación → HAVING → SELECT → DISTINCT si se solicita → ORDER BY → LIMIT.

Antes de escribir una consulta agrupada, decide qué filas participan, qué define cada grupo, qué cálculo se realiza y si debe filtrarse alguna fila o algún grupo.
