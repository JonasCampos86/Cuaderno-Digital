LocalStorage, SessionStorage y Cookies

Clase 33 · Guardar información en el navegador, recuperarla y comprender las diferencias entre cada forma de almacenamiento.

1. Almacenar datos en el navegador

El navegador permite guardar información y recuperarla después, incluso tras recargar una página.

Cookies, localStorage y sessionStorage almacenan datos mediante pares clave–valor, pero tienen diferente duración y funcionamiento.

Podemos utilizarlos para mantener una sesión, recordar preferencias o conservar temporalmente un formulario.

2. Cookies

Las cookies son pequeños datos que el navegador guarda y envía automáticamente al servidor en las peticiones que correspondan.

Un uso habitual es identificar una sesión: 

Inicio de sesión → Servidor comprueba las credenciales
       ↓
Navegador guarda una cookie con un identificador
       ↓
La envía en nuevas peticiones → Servidor reconoce la sesión

El servidor puede establecerlas mediante la cabecera Set-Cookie; el navegador las devuelve mediante Cookie.

Leer y escribir cookies

Desde JavaScript utilizamos document.cookie: 

// Crear una cookie
document.cookie = "user=John";

// Leer las cookies accesibles
console.log(document.cookie);
// Ejemplo: "user=John; tema=oscuro"

// Actualizar user, manteniendo su dominio y ruta
document.cookie = "user=Ana";

Leer document.cookie devuelve una cadena con pares nombre=valor separados por punto y coma.

Escribir en document.cookie no reemplaza todas las cookies: crea o actualiza una.

Codificación

encodeURIComponent() permite representar espacios y caracteres especiales. decodeURIComponent() recupera el texto original. 

document.cookie = "user=" + encodeURIComponent("John Smith");
// user=John%20Smith

Codificar no es cifrar: el contenido no queda protegido como un secreto.

Opciones principales

Opción Función
path Define las rutas a las que se aplica. path=/ abarca todo el sitio.
domain Define el dominio al que se aplica. No podemos escoger un dominio ajeno.
expires Establece una fecha de caducidad.
max-age Establece la duración en segundos desde ahora.

Cookie válida durante una hora: 

document.cookie = "user=John; path=/; max-age=3600";

Caducidad mediante una fecha: 

const fecha = new Date(Date.now() + 86400000);

document.cookie = `user=John; path=/; expires=${fecha.toUTCString()}`;

Sumamos un día en milisegundos y convertimos la fecha al formato UTC requerido.

expires indica cuándo caduca; max-age, cuánto dura.

Sin estas opciones, la cookie es de sesión: su duración queda vinculada a la sesión del navegador.

Para eliminarla, hacemos que caduque: 

document.cookie = "user=; path=/; max-age=0";

Al actualizar o eliminar una cookie debemos respetar su dominio y ruta.

Las cookies tienen una capacidad pequeña, aproximadamente 4 KB por cookie. Podemos inspeccionarlas desde: 

Herramientas de desarrollo → Aplicación → Cookies → Dominio

Una cookie que identifica una sesión es sensible: su robo podría permitir suplantarla. La caducidad no sustituye las demás medidas de seguridad.

Referencia: document.cookie — MDN .

3. Funciones auxiliares para cookies

Podemos definir funciones que simplifiquen su lectura, escritura y eliminación.

getCookie(), setCookie() y deleteCookie() no vienen incorporadas en JavaScript.

getCookie(): obtener un valor

Esta función busca una cookie por su nombre y devuelve su valor decodificado. Si no la encuentra, devuelve undefined. 

function getCookie(name) {
    const matches = document.cookie.match(new RegExp(
        "(?:^|; )" +
        name.replace(/([\.$?*|{}\(\)\[\]\\\/\+^])/g, "\\$1") +
        "=([^;]*)"
    ));

    return matches ? decodeURIComponent(matches[1]) : undefined;
}

La expresión regular localiza la cookie dentro de la cadena. decodeURIComponent() recupera su valor original, deshaciendo la codificación.

Uso:

console.log(getCookie("user")); // "John", si existe
console.log(getCookie("noExiste")); // undefined

getCookie() es una función auxiliar que debemos definir, no una función incorporada de JavaScript.

Esta versión corresponde a la función de JavaScript.info .

setCookie(): crear o actualizar

Recibe el nombre, el valor y un objeto opcional de configuración. Utiliza / como ruta predeterminada. 

function setCookie(name, value, opciones = {}) {
    const ajustes = { path: "/", ...opciones };
    let cookie = `${encodeURIComponent(name)}=${encodeURIComponent(value)}`;

    for (const clave of Object.keys(ajustes)) {
        const valor = ajustes[clave] instanceof Date
            ? ajustes[clave].toUTCString()
            : ajustes[clave];

        cookie += `; ${clave}`;
        if (valor !== true) cookie += `=${valor}`;
    }

    document.cookie = cookie;
}

Uso:

setCookie("user", "John Smith", { "max-age": 3600 });
console.log(getCookie("user")); // "John Smith"

La función construye la cadena, añade las opciones y finalmente escribe la cookie.

deleteCookie(): eliminar

Reutilizamos setCookie() para hacer que la cookie caduque inmediatamente. 

function deleteCookie(name, opciones = {}) {
    setCookie(name, "", { ...opciones, "max-age": -1 });
}

deleteCookie("user");

Si se creó con otra ruta o dominio, debemos pasarlos también al borrarla.

Estas son versiones adaptadas para estudiar; las funciones de referencia están en Funciones de cookies — JavaScript.info .

4. LocalStorage y SessionStorage

Ambos permiten guardar datos en el navegador sin enviarlos automáticamente al servidor.

Su almacenamiento está separado por origen: protocolo, dominio y puerto. Por ejemplo, una dirección HTTP y otra HTTPS no comparten el mismo almacenamiento.

Característica localStorage sessionStorage
Duración Sin caducidad automática; persiste al cerrar y abrir el navegador. Conserva los datos al recargar y normalmente los elimina al cerrar la pestaña.
Al recargar Conserva los datos. Conserva los datos.
Entre pestañas Comparte datos entre pestañas del mismo origen. Cada pestaña mantiene un almacenamiento separado.
Uso típico Recordar preferencias. Conservar datos temporales de una pestaña.

Restaurar una pestaña cerrada puede recuperar su sesión y sus datos; recargarla, por sí solo, no los elimina.

Persistente no significa permanente: el usuario o el navegador pueden borrar los datos.

Los dos utilizan los mismos métodos, pero guardan la información en espacios diferentes.

Referencia: LocalStorage y sessionStorage — JavaScript.info .

5. Métodos y propiedades

Método o propiedad Función
setItem(clave, valor) Crea o actualiza un dato.
getItem(clave) Recupera un valor. Devuelve null si no existe.
removeItem(clave) Elimina un dato.
clear() Elimina todos los datos de ese almacenamiento.
key(indice) Devuelve la clave de una posición, o null si no existe.
length Indica cuántos datos hay almacenados.

Ejemplo:

localStorage.setItem("tema", "oscuro");

const tema = localStorage.getItem("tema");
console.log(tema); // "oscuro"

localStorage.removeItem("tema");

Para trabajar con el almacenamiento de sesión, usamos los mismos métodos: 

sessionStorage.setItem("paso", "2");
console.log(sessionStorage.getItem("paso")); // "2"

clear() no elimina una sola clave: vacía todo el almacenamiento correspondiente.

También existe el acceso como propiedad, por ejemplo localStorage.tema, pero es preferible usar los métodos para evitar conflictos con nombres como length o clear.

Referencia: Storage — MDN .

6. Guardar objetos y arrays: JSON

Las claves y los valores de ambos almacenamientos son cadenas de texto. 

localStorage.setItem("edad", 25);

console.log(localStorage.getItem("edad")); // "25"

Si necesitamos un número, debemos convertirlo: 

const edad = Number(localStorage.getItem("edad"));

Para guardar objetos o arrays utilizamos JSON.stringify(). Para reconstruirlos, JSON.parse(). 

const usuario = { nombre: "Ana", edad: 25 };

// Guardar
localStorage.setItem("usuario", JSON.stringify(usuario));

// Recuperar
const guardado = localStorage.getItem("usuario");
const recuperado = guardado === null ? null : JSON.parse(guardado);

console.log(recuperado);
Objeto → JSON.stringify() → Texto almacenado
Texto recuperado → JSON.parse() → Objeto

Guardar directamente un objeto no conserva su estructura: normalmente se convierte en "[object Object]".

Modificar el objeto recuperado no actualiza el almacenamiento: hay que volver a guardarlo.

Referencia: Uso de Web Storage — MDN .

7. Recorrer los datos almacenados

Podemos obtener las claves y consultar sus valores: 

for (const clave of Object.keys(localStorage)) {
    console.log(clave, localStorage.getItem(clave));
}

Otra opción es recorrer las posiciones mediante length y key(): 

for (let i = 0; i < localStorage.length; i++) {
    const clave = localStorage.key(i);
    console.log(clave, localStorage.getItem(clave));
}

Un for...in sin filtrar puede incluir propiedades heredadas. Además, no debemos depender de un orden concreto de las claves.

8. Evento storage

El evento storage permite detectar cambios realizados desde otro documento que comparte el mismo almacenamiento.

Con localStorage, una pestaña puede reaccionar a los cambios realizados desde otra del mismo origen. 

window.addEventListener("storage", (evento) => {
    console.log("Clave:", evento.key);
    console.log("Antes:", evento.oldValue);
    console.log("Ahora:", evento.newValue);
});
Propiedad Información
key Clave modificada.
oldValue Valor anterior.
newValue Valor nuevo.
url Dirección del documento que hizo el cambio.
storageArea Almacenamiento afectado.

El evento no se dispara en la propia página que realiza el cambio.

Con sessionStorage no comunica pestañas independientes; puede alcanzar documentos del mismo origen dentro de la misma pestaña, como un iframe.

Referencia: Evento storage — MDN .

9. Ejemplo: conservar un borrador

Guardamos lo escrito para recuperarlo al recargar.

HTML

<textarea id="borrador"></textarea>
<button id="borrar" type="button">Borrar borrador</button>

JavaScript, ejecutado después del HTML

const campo = document.querySelector("#borrador");
const boton = document.querySelector("#borrar");

campo.value = localStorage.getItem("borrador") ?? "";

campo.addEventListener("input", () => {
    localStorage.setItem("borrador", campo.value);
});

boton.addEventListener("click", () => {
    localStorage.removeItem("borrador");
    campo.value = "";
});

Al cargar, recuperamos el texto; al escribir, lo guardamos; al pulsar el botón, eliminamos tanto el dato almacenado como el contenido visible.

Si solo necesitamos conservarlo durante la sesión de esa pestaña, podemos sustituir localStorage por sessionStorage.
