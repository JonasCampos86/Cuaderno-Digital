classList y dataset

APIs específicas del DOM para gestionar clases CSS y atributos personalizados data-* desde JavaScript.

1. Punto de partida: los atributos HTML

En la gestión de atributos vimos que los elementos HTML pueden contener información adicional mediante atributos.

Algunos atributos identifican elementos, otros modifican su comportamiento y otros permiten guardar datos asociados al propio elemento. 

<div class="container" data-id="15">
  <button disabled>Avisar</button>
</div>

Los atributos HTML pueden gestionarse desde JavaScript mediante propiedades del objeto DOM o mediante métodos específicos. 

Elemento HTML
        ↓
DOM
        ↓
JavaScript
        ↓
Leer / Modificar / Eliminar atributos

2. El problema especial del atributo class

El atributo class puede contener varias clases separadas por espacios. 

<div class="rojo importante principal"></div>

Podemos acceder al atributo completo mediante la propiedad className. 

const primerDiv = document.querySelector("div");

console.log(primerDiv.className);

className trabaja con el contenido completo del atributo class como una única cadena de texto.

El problema aparece cuando modificamos className directamente. 

primerDiv.className = "activo";
"rojo importante principal"
        ↓
className = "activo"
        ↓
"activo"

Asignar un nuevo valor a className reemplaza toda la cadena de clases existente.

3. Qué es classList

classList permite trabajar con las clases de un elemento de forma individual. 

class="rojo importante principal"
        ↓
classList
        ↓
rojo | importante | principal

Esto permite añadir, eliminar, comprobar, alternar o reemplazar clases sin manipular manualmente toda la cadena.

className trabaja con toda la cadena del atributo class.

classList trabaja con cada clase individualmente. 

className → "rojo importante principal" → Cadena completa

classList → rojo | importante | principal → Clases individuales

classList no es un array real.

classList devuelve un objeto de tipo DOMTokenList.

Un DOMTokenList es una colección especializada para trabajar con tokens separados por espacios, como las clases CSS. 

console.log(primerDiv.classList);

console.log(primerDiv.classList.length);

length permite consultar cuántas clases contiene la colección.

4. Métodos principales de classList

add()

classList.add() añade una o varias clases sin eliminar las existentes. 

primerDiv.classList.add("activo");

primerDiv.classList.add("activo", "visible");

Si intentamos añadir una clase que ya existe, no se duplica.

remove()

classList.remove() elimina una clase concreta sin afectar a las demás. 

primerDiv.classList.remove("importante");

primerDiv.classList.remove("rojo", "principal");

Si la clase indicada no existe, no se produce un error por ese motivo.

contains()

classList.contains() comprueba si un elemento contiene una clase concreta. 

primerDiv.classList.contains("principal");
contains("principal")
        ↓
¿Existe la clase?
        ↓
true / false

contains() no modifica el elemento; únicamente comprueba la existencia de una clase.

toggle()

classList.toggle() añade una clase si no existe y la elimina si ya existe. 

primerDiv.classList.toggle("activo");
No existe
        ↓
add()
        ↓
La añade

Existe
        ↓
remove()
        ↓
La elimina

toggle() es muy útil cuando una clase representa un estado visual, como un menú abierto o cerrado. 

menu.classList.toggle("abierto");
Clic
        ↓
toggle("abierto")
        ↓
Añadir / Eliminar clase
        ↓
Cambiar estado visual

toggle() también devuelve un booleano.

Devuelve true si, después de la operación, la clase queda presente.

Devuelve false si, después de la operación, la clase queda ausente.

El booleano devuelto por toggle() representa el estado final de la clase.

replace()

classList.replace() sustituye una clase existente por otra. 

primerDiv.classList.replace("rojo", "azul");
rojo | importante | principal
        ↓
replace("rojo", "azul")
        ↓
azul | importante | principal

Si la clase antigua no existe, no se realiza el reemplazo.

Resumen de métodos

add()      → Añadir
remove()   → Eliminar
contains() → Comprobar
toggle()   → Alternar
replace()  → Sustituir

classList permite gestionar clases individualmente sin manipular manualmente toda la cadena del atributo class.

5. Qué son los data attributes

Los atributos data-* permiten almacenar información personalizada dentro de un elemento HTML. 

<article data-id="1"></article>

<article data-price="23.5"></article>

<article data-peso-kg="6.7"></article>

Estos atributos permiten asociar información adicional al propio elemento.

Por ejemplo, una tarjeta de producto puede guardar su identificador, su precio o su peso. 

<article
  class="producto"
  data-id="1"
  data-price="23.5"
  data-peso-kg="6.7"
>
</article>

data-id puede guardar un identificador.

data-price puede guardar un precio.

data-peso-kg puede guardar un peso.

6. Acceder a data-* mediante dataset

Como los data-* siguen siendo atributos HTML, pueden leerse con getAttribute(). 

const primerProducto = document.querySelector(".producto");

const precio = primerProducto.getAttribute("data-price");

console.log(precio);
Resultado
        ↓
"23.5"

dataset permite acceder específicamente a los atributos data-* de un elemento. 

primerProducto.dataset.id;

primerProducto.dataset.price;

primerProducto.dataset.pesoKg;
data-id      → dataset.id
data-price   → dataset.price
data-peso-kg → dataset.pesoKg

dataset elimina el prefijo data- y transforma los nombres compuestos a camelCase.

7. Conversión a camelCase

Cuando un atributo data-* tiene varias palabras separadas por guiones, dataset lo transforma a camelCase. 

<article data-peso-kg="6.7"></article>
element.dataset.pesoKg;
data-peso-kg
        ↓
eliminar "data-"
        ↓
peso-kg
        ↓
camelCase
        ↓
pesoKg

data-mi-dato se convierte en dataset.miDato.

Error frecuente: 

element.dataset.peso-kg;

Forma correcta: 

element.dataset.pesoKg;

8. Leer, modificar, crear y eliminar datos

Leer datos

const id = primerProducto.dataset.id;
const precio = primerProducto.dataset.price;
const peso = primerProducto.dataset.pesoKg;
"1"
"23.5"
"6.7"

Los valores obtenidos mediante dataset son cadenas de texto.

Si necesitamos trabajar con números, debemos convertirlos manualmente. 

const precio = Number(primerProducto.dataset.price);

dataset no interpreta automáticamente si un dato representa un número, un booleano u otro tipo.

Modificar un data attribute

Podemos modificar un atributo data-* asignando un nuevo valor a una propiedad de dataset. 

primerProducto.dataset.price = "30";
dataset.price = "30"
        ↓
data-price="30"

Crear un nuevo data attribute

Si la propiedad no existía, la asignación crea un nuevo atributo. 

primerProducto.dataset.stock = "8";
<article data-stock="8"></article>

Asignar una nueva propiedad a dataset crea el correspondiente atributo data-*.

Eliminar un data attribute

Para eliminar un atributo gestionado mediante dataset utilizamos delete. 

delete primerProducto.dataset.price;
delete dataset.price
        ↓
Eliminar data-price

Asignar una cadena vacía no es lo mismo que eliminar el atributo. 

primerProducto.dataset.price = "";
<article data-price=""></article>

Para eliminar realmente el atributo mediante dataset, utilizamos delete.

9. getAttribute() frente a dataset

primerProducto.getAttribute("data-price");

primerProducto.dataset.price;

getAttribute() trabaja con cualquier atributo.

dataset está especializado en atributos data-*. 

getAttribute("data-price")
        ↓
Método genérico

dataset.price
        ↓
API específica para data-*

Cuando trabajamos específicamente con atributos data-*, dataset ofrece una sintaxis más directa y expresiva.

10. Cuándo usar y cuándo no usar data-*

Los data attributes sirven para asociar información adicional a un elemento cuando tiene sentido para el comportamiento de la página.

Ejemplos reales: ID interno de un producto, precio asociado a una tarjeta, categoría de un elemento, estado auxiliar o identificador necesario para una interacción JavaScript. 

<button data-product-id="42">
  Añadir al carrito
</button>
boton.dataset.productId;
Botón
        ↓
data-product-id
        ↓
dataset.productId
        ↓
JavaScript
        ↓
Acción

Los data attributes no deben sustituir atributos HTML que ya tienen una función específica.

Mal planteamiento: 

<input data-required="true">

Correcto: 

<input required>

No debemos inventar un data-* cuando HTML ya dispone de un atributo semántico para esa función.

Tampoco debemos utilizar data-* para ocultar información que debería ser visible o accesible para el usuario.

11. Relación entre classList y dataset

class
        ↓
classList
        ↓
Gestionar clases individualmente

data-*
        ↓
dataset
        ↓
Gestionar datos personalizados

classList especializa la gestión del atributo class, mientras que dataset especializa la gestión de los atributos data-*.

Esta es la idea conceptual que une toda la clase.

Ejemplo combinado

<article
  class="producto"
  data-id="1"
  data-price="23.5"
>
</article>
const producto = document.querySelector(".producto");

const precio = Number(producto.dataset.price);

producto.classList.add("seleccionado");
dataset
        ↓
Lee información del producto

classList
        ↓
Modifica el estado visual del producto

dataset puede almacenar información asociada al elemento y classList puede reflejar visualmente su estado.

12. Resumen final

classList

className trabaja con toda la cadena de clases.

classList trabaja con clases individuales.

classList devuelve un DOMTokenList, no un array real.

add() añade clases.

remove() elimina clases.

contains() comprueba clases.

toggle() alterna clases.

replace() sustituye clases. 

class
        ↓
classList
        ↓
add / remove / contains / toggle / replace

dataset

Los atributos data-* almacenan información personalizada asociada a un elemento.

dataset permite acceder específicamente a los atributos data-*.

El prefijo data- desaparece al acceder mediante dataset.

Los nombres compuestos se transforman a camelCase.

Los valores obtenidos mediante dataset son cadenas de texto. 

element.dataset.price;
element.dataset.price = "30";
delete element.dataset.price;
data-price
        ↓
dataset.price
        ↓
Leer / Modificar / Eliminar

classList gestiona clases y dataset gestiona información personalizada asociada al elemento.
