Gestión de eventos en JavaScript

Detectar sucesos de la página y ejecutar código cuando el usuario interactúa con los elementos.

1. Qué es un evento

Un evento es un suceso que ocurre en una página y que JavaScript puede detectar para ejecutar una determinada acción.

Muchos eventos se producen como consecuencia de una acción realizada por el usuario.

Algunos ejemplos son pulsar un botón, hacer clic sobre un elemento, escribir mediante el teclado o interactuar con alguna parte de la página.

Los eventos permiten que JavaScript responda a sucesos que ocurren en la página, muchos de ellos provocados por el usuario. 

Usuario / página
      ↓
Ocurre un suceso
      ↓
EVENTO
      ↓
JavaScript lo detecta
      ↓
Ejecuta código

2. Los eventos funcionan de forma asíncrona

JavaScript no necesita detener el programa esperando a que ocurra el evento.

Preparamos previamente el código que deberá ejecutarse cuando ese evento se produzca. 

Preparar código
      ↓
El programa continúa
      ↓
Ocurre el evento
      ↓
Se ejecuta la función asociada

El código queda preparado para responder cuando el evento se produzca.

A permanecer pendientes de un evento se le suele llamar escuchar un evento.

4. Primera forma: onclick en HTML

Esta forma no la utilizaremos como forma habitual de trabajo.

HTML permite asociar directamente un evento a una etiqueta mediante un atributo. 

<button onclick="mostrarAlert()">
  Prueba de botón con la primera manera
</button>

La función se encuentra definida en JavaScript. 

function mostrarAlert() {
  alert("Botón pulsado");
}
<button>
      ↓
onclick
      ↓
mostrarAlert()
      ↓
Se ejecuta la función

El problema es que estamos introduciendo comportamiento JavaScript dentro del HTML. 

HTML → estructura

JavaScript → comportamiento

Además, el HTML necesita conocer el nombre de una función JavaScript.

Si posteriormente modificamos el nombre de esa función en JavaScript, podríamos olvidar actualizar las referencias existentes en el HTML.

Esta forma crea una dependencia entre el HTML y las funciones definidas en JavaScript.

5. Segunda forma: crear onclick desde JavaScript

Esta forma tampoco la utilizaremos.

Podemos crear el atributo desde JavaScript mediante setAttribute(). 

let segundoBoton =
  document.getElementById("segundoBoton");

segundoBoton.setAttribute(
  "onClick",
  "mostrarAlert()"
);
JavaScript
      ↓
setAttribute()
      ↓
Crea onclick
      ↓
HTML

Seguimos utilizando un atributo HTML onclick; simplemente lo estamos creando desde JavaScript.

Esta segunda forma tampoco será la que utilizaremos.

6. addEventListener(): la forma que utilizaremos

addEventListener() permite registrar una función que se ejecutará cuando ocurra un determinado evento.

Sintaxis

elemento.addEventListener(
  "evento",
  funcion
);

Primer argumento: evento que queremos escuchar.

Segundo argumento: función que se ejecutará cuando ocurra el evento. 

Elemento
      ↓
addEventListener()
      ↓
Evento
      ↓
Callback

Para gestionar eventos utilizaremos addEventListener().

Ejemplo

let tercerBoton =
  document.getElementById("tercerBoton");

tercerBoton.addEventListener(
  "click",
  function () {
    alert("Botón pulsado");
  }
);

JavaScript queda escuchando el evento "click".

Cuando el usuario pulsa el botón, se ejecuta la función asociada.

No ejecutamos nosotros directamente esa función; JavaScript la ejecutará cuando ocurra el evento.

7. El callback

La función asociada al evento recibe el nombre de callback.

Es el código que JavaScript ejecutará cuando ocurra el evento. 

addEventListener("click", funcion)
                 ↓
              espera
                 ↓
               click
                 ↓
              funcion()

Cuando pasamos una función como callback, pasamos su referencia sin ejecutarla.

Correcto: 

tercerBoton.addEventListener(
  "click",
  mostrarConsole
);

Incorrecto: 

tercerBoton.addEventListener(
  "click",
  mostrarConsole()
);
mostrarConsole
      ↓
Referencia a la función


mostrarConsole()
      ↓
Ejecutar la función

8. Función declarada o arrow function

El callback puede escribirse de diferentes formas.

Función declarada

function mostrarConsole() {
  console.log(
    "Escribiendo algo por consola"
  );
}

tercerBoton.addEventListener(
  "click",
  mostrarConsole
);

Arrow function

const accion = () =>
  alert("Hello!");

button.addEventListener(
  "click",
  accion
);

La forma de escribir la función puede cambiar, pero sigue actuando como callback del listener.

9. Múltiples listeners

Un mismo elemento puede tener varios listeners asociados al mismo evento. 

tercerBoton.addEventListener(
  "click",
  function () {
    alert("Botón pulsado");
  }
);

tercerBoton.addEventListener(
  "click",
  mostrarConsole
);
CLICK
  │
  ├── Listener 1 → alert()
  │
  └── Listener 2 → mostrarConsole()

addEventListener() permite registrar varios callbacks para un mismo evento.

10. Eliminar un listener: removeEventListener()

removeEventListener() permite eliminar un listener registrado anteriormente.

Sintaxis

elemento.removeEventListener(
  "evento",
  funcion
);

Para eliminar un listener debemos indicar el mismo tipo de evento y la misma referencia de función utilizados al registrarlo.

Ejemplo correcto

function accion() {
  alert("Hello!");
}

button.addEventListener(
  "click",
  accion
);

button.removeEventListener(
  "click",
  accion
);
                accion
                  │
        ┌─────────┴─────────┐
        ↓                   ↓

addEventListener()   removeEventListener()

Ambos métodos utilizan la misma referencia de función.

11. Problema con las funciones anónimas

Si registramos un listener con una función anónima y después intentamos eliminarlo escribiendo otra función anónima igual, el listener no se elimina. 

tercerBoton.addEventListener(
  "click",
  function () {
    alert("Botón pulsado");
  }
);

Después intentamos eliminarlo mediante: 

tercerBoton.removeEventListener(
  "click",
  function () {
    alert("Botón pulsado");
  }
);

El listener no se elimina.

Aunque las dos funciones contienen exactamente el mismo código, son funciones diferentes. 

function () { ... }
        ↓
    Función A


function () { ... }
        ↓
    Función B


Función A ≠ Función B

Dos funciones pueden contener exactamente el mismo código y seguir siendo funciones distintas.

Si queremos eliminar posteriormente el listener

Conviene conservar la referencia a la función. 

function mostrarAlert() {
  alert("Botón pulsado");
}

tercerBoton.addEventListener(
  "click",
  mostrarAlert
);

tercerBoton.removeEventListener(
  "click",
  mostrarAlert
);

Guardar la función permite reutilizar exactamente la misma referencia.

12. El objeto Event

Cuando ocurre un evento, JavaScript proporciona un objeto con información relacionada con ese evento.

Podemos recibirlo como parámetro del callback. 

cuartoBoton.addEventListener(
  "click",
  function (event) {
    console.log(
      "He pulsado el cuarto botón."
    );

    console.log(event);
  }
);
Ocurre el evento
      ↓
JavaScript proporciona Event
      ↓
Callback recibe event
      ↓
Consultamos información

El objeto Event nos permite conocer información sobre lo que acaba de ocurrir.

13. Propiedades del objeto Event

El objeto Event dispone de propiedades que contienen información relacionada con el evento.

Propiedad Utilidad
altKey Indica si la tecla Alt estaba pulsada durante el evento
button Indica qué botón del ratón activó el evento
charCode Código del carácter pulsado
clientX Coordenada X del ratón respecto a la ventana
clientY Coordenada Y del ratón respecto a la ventana
ctrlKey Indica si Ctrl estaba pulsada durante el evento
pageX Coordenada X del ratón respecto al documento completo
pageY Coordenada Y del ratón respecto al documento completo
screenX Coordenada X del evento respecto a la pantalla
screenY Coordenada Y del evento respecto a la pantalla
shiftKey Indica si Shift estaba pulsada durante el evento
target Referencia al elemento que lanzó el evento
timeStamp Momento asociado a la creación del evento
type Nombre del evento

No es necesario memorizar todas estas propiedades de golpe.

Lo importante es comprender que Event contiene información sobre el evento producido.

14. event.target

event.target permite conocer qué elemento ha originado el evento. 

let botones =
  document.getElementsByTagName("button");

for (let boton of botones) {
  boton.addEventListener(
    "click",
    (event) =>
      console.log(
        "He pulsado el botón",
        event.target
      )
  );
}

En este ejemplo existen varios botones, por lo que event.target permite identificar exactamente cuál de ellos ha originado el evento. 

Botón 1 ─┐
Botón 2 ─┼─→ Usuario pulsa uno
Botón 3 ─┤
Botón 4 ─┘

        EVENTO
          ↓
     event.target
          ↓
Elemento que lo originó

event.target referencia al elemento concreto que ha provocado el evento.

16. Resumen final

Un evento es un suceso que JavaScript puede detectar.

Los eventos permiten que JavaScript responda a sucesos que ocurren en la página.

El código queda preparado para ejecutarse cuando ocurra el evento.

Utilizar onclick directamente en HTML es una forma que debemos evitar.

Crear onclick mediante setAttribute() tampoco soluciona realmente el problema.

Para gestionar eventos utilizaremos addEventListener().

addEventListener() recibe el nombre del evento y una función callback.

El callback se ejecutará cuando el evento ocurra.

Un elemento puede tener varios listeners asociados al mismo evento.

removeEventListener() permite eliminar un listener registrado anteriormente.

Para eliminar un listener debemos utilizar el mismo evento y la misma referencia de función utilizados al registrarlo.

Dos funciones anónimas escritas exactamente igual siguen siendo funciones diferentes.

El objeto Event contiene información sobre el evento producido.

event.target permite conocer qué elemento originó el evento.
