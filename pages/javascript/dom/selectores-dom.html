Selectores del DOM

Cómo encontrar elementos del documento HTML desde JavaScript para poder leerlos, modificarlos o trabajar con ellos.

1. El DOM

El DOM, Document Object Model, es la representación del documento HTML como una estructura de objetos que JavaScript puede leer y modificar.

Cuando el navegador carga una página, interpreta el HTML y construye una estructura interna con la que JavaScript puede trabajar.

El DOM es el puente entre HTML y JavaScript. 

HTML
  ↓
Navegador interpreta el documento
  ↓
DOM
  ↓
JavaScript puede leer y modificar elementos

JavaScript no modifica directamente el archivo HTML original; modifica la representación del documento que el navegador tiene en memoria.

2. Objeto document

document es el punto de entrada principal al DOM.

La mayoría de selectores parten de document porque representa el documento HTML cargado en el navegador. 

document.getElementById()
document.getElementsByClassName()
document.getElementsByTagName()
document.getElementsByName()
document.querySelector()
document.querySelectorAll()

Si queremos buscar elementos dentro del HTML desde JavaScript, normalmente empezamos desde document.

3. getElementById()

getElementById() busca un elemento por el valor de su atributo id. 

<p id="p1">Párrafo con id establecido</p>

const pConId = document.getElementById("p1");

Devuelve un HTMLElement si encuentra el elemento.

Devuelve null si no encuentra ningún elemento con ese id.

Los id deberían ser únicos dentro de una misma página. 

const parrafo = document.getElementById("noExiste");

console.log(parrafo); // null

Si intentamos acceder a una propiedad de null, JavaScript dará error.

4. getElementsByClassName()

getElementsByClassName() busca todos los elementos que tengan una determinada clase. 

<p class="importante">Primer elemento</p>
<div class="importante">Segundo elemento</div>

const elementosImportantes =
  document.getElementsByClassName("importante");

Devuelve siempre un HTMLCollection.

Aunque solo encuentre un elemento, el resultado será una colección. 

elementosImportantes[0];
elementosImportantes[1];

No podemos tratar directamente una colección como si fuera un único elemento. 

// Incorrecto
document.getElementsByClassName("importante").textContent;

// Correcto
document.getElementsByClassName("importante")[0].textContent;

5. getElementsByTagName()

getElementsByTagName() busca todos los elementos que tengan una determinada etiqueta HTML. 

const parrafos = document.getElementsByTagName("p");

Devuelve siempre un HTMLCollection.

Si usamos getElementsByTagName("p"), JavaScript buscará todos los párrafos del documento. 

parrafos[0];
parrafos[1];
parrafos[2];

Este selector solo busca por etiqueta. No busca por clase, id ni atributo name.

6. getElementsByName()

getElementsByName() busca elementos que tengan un determinado atributo name. 

<p name="nombreimportante">Primer elemento</p>
<p name="nombreimportante">Segundo elemento</p>

const elementosConName =
  document.getElementsByName("nombreimportante");

Devuelve un NodeList.

No importa la etiqueta del elemento. Lo importante es el valor del atributo name. 

<div name="import"></div>
<p name="import"></p>
<input name="import">

Los tres elementos pueden ser seleccionados porque los tres tienen name="import".

7. querySelector()

querySelector() permite buscar elementos utilizando selectores CSS.

Devuelve solamente el primer elemento que cumpla la condición. 

const primerParrafo = document.querySelector("p");

También permite usar selectores más concretos. 

document.querySelector("#p1");
document.querySelector(".importante");
document.querySelector("div");
document.querySelector("div p");
document.querySelector("input[type='text']");

Devuelve un HTMLElement si encuentra un elemento.

Devuelve null si no encuentra ningún elemento.

querySelector() es muy versátil, pero hay que recordar que puede devolver null.

8. querySelectorAll()

querySelectorAll() funciona como querySelector(), pero devuelve todos los elementos que cumplen la condición. 

const parrafos = document.querySelectorAll("p");

Devuelve un NodeList.

Podemos acceder a cada elemento mediante índices. 

parrafos[0];
parrafos[1];
parrafos[2];

También podemos recorrer el NodeList con forEach(). 

parrafos.forEach(parrafo => {
  console.log(parrafo.textContent);
});

querySelectorAll() devuelve una colección, no un elemento individual. 

// Incorrecto
document.querySelectorAll("p").textContent;

// Correcto
document.querySelectorAll("p")[0].textContent;

9. HTMLCollection y NodeList

Algunos selectores devuelven un único elemento y otros devuelven colecciones de elementos.

HTMLCollection y NodeList son colecciones de elementos o nodos del DOM. 

const parrafosPorEtiqueta =
  document.getElementsByTagName("p");

const parrafosPorSelector =
  document.querySelectorAll("p");

getElementsByTagName("p") devuelve un HTMLCollection.

querySelectorAll("p") devuelve un NodeList.

HTMLCollection y NodeList no son arrays reales.

Si queremos trabajar con métodos de array como map(), filter() o reduce(), podemos convertir la colección en un array real. 

const arrayParrafos = [...document.querySelectorAll("p")];

arrayParrafos.map(parrafo => parrafo.textContent);

El spread operator permite convertir colecciones iterables del DOM en arrays reales.

10. Cuándo usar cada selector

Si queremos un elemento concreto por id, podemos usar getElementById().

Si queremos el primer elemento que cumpla una condición CSS, usamos querySelector().

Si queremos varios elementos que cumplan una condición CSS, usamos querySelectorAll().

En proyectos modernos, querySelector() y querySelectorAll() son muy habituales porque usan la misma sintaxis que CSS. 

¿Qué elemento quiero seleccionar?
        ↓
¿Qué condición cumple?
        ↓
¿Quiero uno o varios?
        ↓
¿Qué selector responde mejor a esa condición?

La clave no es memorizar métodos, sino entender qué elemento queremos encontrar.

11. Resumen final

getElementById() busca por id y devuelve HTMLElement o null.

getElementsByClassName() busca por clase y devuelve HTMLCollection.

getElementsByTagName() busca por etiqueta y devuelve HTMLCollection.

getElementsByName() busca por atributo name y devuelve NodeList.

querySelector() busca con selector CSS y devuelve el primer elemento encontrado.

querySelectorAll() busca con selector CSS y devuelve todos los elementos encontrados.

Si un selector devuelve una colección, no podemos tratarla como un único elemento.

Los selectores permiten que JavaScript encuentre elementos del DOM para poder trabajar con ellos.
