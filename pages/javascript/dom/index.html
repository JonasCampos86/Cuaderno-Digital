DOM

Selección, creación, modificación e inserción de elementos en el documento.

Contenidos del bloque

Este bloque reúne los conceptos principales para manipular el documento HTML desde JavaScript.

  • Selectores del DOM Métodos para seleccionar elementos existentes dentro del documento.
  • Creación de elementos Crear nodos, añadir contenido e insertarlos en el DOM.
  • Gestión de atributos Leer, modificar y eliminar atributos HTML desde JavaScript.
  • classList y dataset Gestionar clases individuales y atributos data-* desde JavaScript.
  • Insertar y movernos por el DOM Insertar, mover, reemplazar, eliminar elementos y recorrer la estructura del DOM.
  • Gestión de eventos Detectar sucesos de la página, usar listeners, callbacks, Event y event.target.
  • Tipos de eventos Eventos de formulario, ratón, teclado, multimedia, carga, ventana y portapapeles.
  • Emisión y propagación de eventos CustomEvent, dispatchEvent(), captura, burbujeo y control de eventos; target y currentTarget.
