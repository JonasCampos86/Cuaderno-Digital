2. Propiedades de un elemento

Antes de insertar o recorrer elementos, conviene distinguir algunas propiedades que permiten leer el contenido de un elemento de formas diferentes.

Propiedad ¿Qué obtiene? Tiene en cuenta el CSS
innerText Solo el texto visible Sí
textContent Todo el texto del nodo No
innerHTML HTML interno del elemento —
outerHTML Todo el elemento, incluidas sus etiquetas —

Estas propiedades permiten consultar el contenido de un elemento, pero no todas devuelven lo mismo.

3. textContent

textContent devuelve todo el texto contenido en el elemento. 

const producto = document.querySelector(".producto");

console.log(producto.textContent);

textContent ignora si ese texto está oculto mediante CSS.

      ▼

4. innerText

innerText devuelve únicamente el texto que realmente es visible después del renderizado. 

console.log(producto.innerText);

innerText tiene en cuenta reglas CSS como display: none. 

Elemento
      │
      ▼
innerText
      │
      ▼
Solo el texto visible

5. innerHTML

innerHTML devuelve el contenido HTML interno de un elemento. 

console.log(producto.innerHTML);

Resultado aproximado: 

<h3>Rueda de tacos</h3>
<p>...</p>

innerHTML no devuelve solo texto: devuelve el HTML que hay dentro del elemento.

6. outerHTML

outerHTML devuelve el elemento completo. 

console.log(producto.outerHTML);

Resultado: 

<article class="producto" ...>
  ...
</article>

outerHTML incluye el propio elemento y su contenido.

8. API clásica de nodos

La API clásica de nodos trabaja insertando, eliminando o sustituyendo nodos hijos.

Método ¿Qué hace? Devuelve
appendChild() Inserta como último hijo El nodo insertado
removeChild() Elimina un hijo El nodo eliminado
replaceChild() Sustituye un hijo El nodo sustituido

appendChild()

appendChild() inserta el nodo como último hijo del elemento. 

const nuevo = document.createElement("p");

nuevo.textContent = "Nuevo párrafo";

producto.appendChild(nuevo);
article
│
├── h3
├── p
└── nuevo p

removeChild()

removeChild() elimina un hijo concreto del elemento. 

producto.removeChild(nuevo);
Padre
│
└── hijo eliminado

replaceChild()

replaceChild() sustituye un hijo por otro. 

producto.replaceChild(nuevoH2, actualH3);
Antes:

article
│
└── h3

Después:

article
│
└── h2

9. API moderna de elementos

Los navegadores modernos incorporan métodos más cómodos que la API clásica de nodos.

Método Posición
append() Final del elemento
prepend() Inicio del elemento
before() Antes del elemento
after() Después del elemento
replaceWith() Sustituye el elemento
remove() Elimina el elemento

Este esquema resume prácticamente toda la API moderna de inserción. 

before()

──────────────

<div>

    prepend()

    contenido

    append()

</div>

──────────────

after()

before()

before() inserta el nuevo nodo justo antes del elemento. 

titulo.before(nuevoH2);

after()

after() inserta el nuevo nodo justo después del elemento. 

titulo.after(nuevoH2);

replaceWith()

replaceWith() sustituye directamente el elemento. 

titulo.replaceWith(nuevoH2);

remove()

remove() elimina el propio elemento sin necesidad de acceder al padre. 

titulo.remove();

10. API clásica vs API moderna

Ambas APIs siguen siendo válidas.

API clásica API moderna
appendChild() append()
removeChild() remove()
replaceChild() replaceWith()

En proyectos actuales suele verse con más frecuencia la API moderna por ser más expresiva.

12. Navegar por el DOM mediante nodos

A diferencia del apartado anterior, aquí también aparecen los nodos de texto y comentarios.

Propiedad Devuelve

nextSibling Nodo siguiente

console.log(producto.childNodes);

childNodes puede incluir elementos HTML, nodos de texto y comentarios.

13. Elementos vs nodos

Esta es la diferencia más importante de toda la clase.

Si únicamente queremos trabajar con etiquetas HTML, normalmente utilizaremos la API de elementos.

14. Resumen final

textContent obtiene todo el texto.

innerText obtiene únicamente el texto visible.

innerHTML devuelve el HTML interno.

outerHTML devuelve el elemento completo.

appendChild() inserta un nodo como último hijo.

removeChild() elimina un hijo.

replaceChild() sustituye un hijo.

append(), prepend(), before(), after(), replaceWith() y remove() forman la API moderna de manipulación del DOM.

children trabaja únicamente con elementos HTML.

childNodes incluye también nodos de texto y comentarios.

Comprender la diferencia entre elementos y nodos es la clave para entender la navegación por el DOM.
