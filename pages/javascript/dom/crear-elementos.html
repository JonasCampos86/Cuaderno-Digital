Creación de elementos del DOM

Cómo crear nodos desde JavaScript, añadirles contenido e insertarlos dentro del documento.

1. Crear elementos

En la clase anterior aprendimos a seleccionar elementos que ya existían en el documento HTML.

Ahora aprendemos a crear elementos nuevos desde JavaScript e insertarlos en el documento.

El DOM no solo permite leer el HTML; también permite construirlo dinámicamente.

Una aplicación de notas puede crear una nota nueva cuando pulsamos “Añadir”.

Un chat puede crear un mensaje nuevo cuando alguien escribe.

Una tienda online puede crear tarjetas de productos cuando recibe datos del servidor.

JavaScript puede crear elementos HTML que originalmente no existían en el archivo .html.

2. Flujo de creación

Para crear contenido dinámico en el DOM seguiremos casi siempre el mismo proceso. 

Crear el elemento
        ↓
Añadir contenido
        ↓
Insertarlo en otro nodo
        ↓
Conectarlo al documento
        ↓
El usuario puede verlo

Este flujo será uno de los más repetidos durante todo el bloque del DOM.

Crear un elemento y verlo en pantalla son dos cosas distintas.

3. createElement()

createElement() crea un nuevo elemento HTML en memoria. 

const primerParrafo = document.createElement("p");

El navegador crea un elemento <p> completamente nuevo.

Ese elemento todavía no pertenece al documento.

Crear un elemento no significa que aparezca automáticamente en la página. 

createElement()
        ↓
Elemento creado en memoria
        ↓
Todavía no forma parte del DOM visible

Es como fabricar un mueble: existe, pero todavía no está colocado dentro de la habitación.

4. textContent

textContent permite insertar texto dentro de un elemento. 

const parrafo = document.createElement("p");

parrafo.textContent =
  "Hola <strong>soy el contenido</strong> del párrafo";

Todo el contenido será tratado como texto plano.

textContent nunca interpreta etiquetas HTML. 

textContent
        ↓
Todo se considera texto
        ↓
No se crean etiquetas HTML

Si queremos mostrar el nombre de un usuario, una descripción o un mensaje de error, textContent suele ser la mejor opción.

5. innerHTML

innerHTML permite insertar e interpretar código HTML dentro de un elemento. 

const parrafo = document.createElement("p");

parrafo.innerHTML =
  "Hola <strong>soy el contenido</strong> del párrafo";

En este caso, el navegador analiza la cadena como HTML.

innerHTML analiza la cadena recibida como HTML y crea los nodos del DOM correspondientes. 

innerHTML
        ↓
El navegador analiza la cadena
        ↓
Si encuentra etiquetas
        ↓
Crea nodos HTML reales

innerHTML debe usarse con cuidado si el contenido viene de un usuario, porque puede generar problemas de seguridad.

Si solo queremos mostrar texto, textContent suele ser más seguro que innerHTML.

6. createTextNode()

createTextNode() crea un nodo cuyo contenido es únicamente texto. 

const contenido = document.createTextNode(
  "Contenido de tipo texto del tercer párrafo"
);

A diferencia de textContent, aquí el texto se crea como un nodo independiente.

Un texto también puede existir como nodo independiente dentro del DOM. 

<p>Hola</p>

p
│
└── "Hola"

El <p> es un nodo elemento. El texto "Hola" es un nodo de texto.

En código moderno muchas veces usaremos textContent porque es más directo, pero createTextNode() ayuda a entender cómo funciona el DOM por dentro.

7. appendChild()

appendChild() inserta un nodo como último hijo de otro nodo. 

const parrafo = document.createElement("p");

const contenido = document.createTextNode("Hola DOM");

parrafo.appendChild(contenido);

El nodo de texto pasa a estar dentro del elemento <p>. 

Nodo de texto
        ↓
appendChild()
        ↓
Se convierte en hijo del <p>

appendChild() no crea nodos; inserta o mueve nodos existentes.

Meter texto dentro de un párrafo no significa automáticamente meter el párrafo dentro de la página.

8. Insertar un elemento en el DOM

Para que un elemento aparezca en la página, debe formar parte del árbol del DOM conectado al documento. 

<div id="contenedor"></div>
const contenedor = document.getElementById("contenedor");

const parrafo = document.createElement("p");

parrafo.textContent = "Soy un párrafo creado desde JavaScript";

contenedor.appendChild(parrafo);
Elemento en memoria
        ↓
appendChild()
        ↓
Elemento conectado al DOM
        ↓
Elemento visible para el usuario

El navegador actualiza automáticamente la página cuando cambia el DOM conectado al documento.

Un nodo solo puede pertenecer a un único lugar del DOM al mismo tiempo.

Si usamos appendChild() con un nodo que ya estaba en otro sitio, no se copia: se mueve.

9. isConnected

isConnected indica si un nodo pertenece actualmente al documento. 

const parrafo = document.createElement("p");

console.log(parrafo.isConnected);

document.body.appendChild(parrafo);

console.log(parrafo.isConnected);
false
true

Al principio, el párrafo existe solo en memoria. Después de insertarlo en document.body, ya pertenece al documento.

isConnected solo informa del estado del nodo; no modifica el DOM.

Error frecuente: pensar que isConnected conecta el elemento al DOM.

10. createComment()

createComment() crea un nodo de tipo comentario. 

const comentario =
  document.createComment("Estos son mis comentarios");

document.body.appendChild(comentario);
<!-- Estos son mis comentarios -->

Los comentarios no se ven visualmente en la página, pero sí forman parte del DOM.

createComment() demuestra que el DOM puede contener nodos que no son elementos visibles.

11. Resumen final

createElement() crea un elemento HTML en memoria.

textContent añade texto plano.

innerHTML añade HTML interpretado.

createTextNode() crea un nodo de texto independiente.

appendChild() inserta o mueve un nodo dentro de otro nodo.

isConnected indica si un nodo pertenece al documento.

createComment() crea un nodo comentario.

Crear un nodo no significa verlo en pantalla; para verlo debe estar conectado al DOM.

Entender el flujo crear → preparar → insertar es más importante que memorizar métodos sueltos.
