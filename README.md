# 📚 Cuaderno Digital

Aplicación web personal de estudio creada para organizar, consultar y repasar de forma clara y navegable los contenidos de mi formación en Desarrollo Web Full Stack.

El proyecto nace con un doble objetivo: convertir mis apuntes en una herramienta útil de estudio y utilizar su desarrollo como parte práctica de mi aprendizaje.

Cuaderno Digital evoluciona progresivamente junto con mis conocimientos, incorporando nuevas tecnologías, módulos y funcionalidades únicamente cuando existe contenido real que lo necesita.

---

## 🌐 Demo

👉 [Ver Cuaderno Digital online](https://cuaderno-digital-apuntes.netlify.app)

---

## 🎯 Objetivo del proyecto

Cuaderno Digital no pretende ser únicamente un repositorio de apuntes.

La idea es transformar el contenido de mi formación en una aplicación web organizada que me permita:

- Consultar los contenidos de forma rápida.
- Mantener los apuntes separados por tecnologías y módulos.
- Crear una navegación clara entre temas.
- Reforzar mediante práctica los conocimientos adquiridos.
- Aplicar progresivamente nuevas técnicas de desarrollo web.
- Trabajar sobre un proyecto real que pueda crecer con el tiempo.

El proyecto está planteado como una aplicación en evolución continua, evitando añadir estructuras, tecnologías o funcionalidades antes de que exista una necesidad real para utilizarlas.

---

## ✨ Características actuales

- Navegación organizada por tecnologías y módulos.
- Lecciones independientes para cada tema.
- Índices específicos para facilitar la navegación.
- Sección dedicada a JavaScript.
- Módulo específico para el DOM.
- Organización modular de estilos.
- Diseño adaptable a distintos tamaños de pantalla.
- Desarrollo y compilación mediante Vite.
- Control de versiones con Git y GitHub.
- Despliegue público mediante Netlify.
